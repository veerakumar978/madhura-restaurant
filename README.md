# Madhura Multicuisine Restaurant — Jangareddygudem
> **A table for every taste.** An elegant classic heritage digital dining experience inspired by the authentic flavors of Andhra, signature biryanis, tandoor, and coastal delicacies.

---

## ✦ Key Experiences & Features

1. **Cinematic Welcome Video**:
   - High-definition opening welcoming visitors to Madhura.
   - Sticky scroll transition that gracefully transforms into the website as the visitor scrolls down.
   - Continuous seamless loop with reactive scroll-up detection.

2. **Hero Section (The Table Begins Here)**:
   - Editorial quotation typography in Cormorant Garamond & Playfair Display.
   - 360° steaming signature **Ulavacharu Kodi Pulav** floating seamlessly on warm parchment.

3. **The Madhura Experience**:
   - Classic single-photo automatic slideshow highlighting interior dining rooms.
   - Fullscreen modal inspection with keyboard navigation.

4. **Explore the Menu**:
   - Authentic heritage physical menu architecture with category navigation and dotted leaders.
   - Classical pricing and dish descriptions.

5. **The Menu Book (Real Archival Menu Pages)**:
   - All 5 physical printed menu pages displayed on desktop in a single row.
   - Interactive zoom & swipe modal reader.

6. **The Visit (Find Your Table)**:
   - Architectural night elevation photograph of the Jangareddygudem landmark.
   - Interactive contact cards: Google Maps location, WhatsApp quick chat, Instagram, and direct phone call.

7. **Final Cinematic Memory Ending**:
   - Illustrated luxury restaurant dining scene rendered in monochrome warm ivory against deep dark brown.
   - Server serving freshly prepared hot biryani with visible steps, gentle steam rising, and seated guests reacting.
   - Emotional theatrical closure: *"Thank you for visiting us. Good food is shared. Good moments are remembered."*

## ✦ Deploying to Vercel

### Option 1: Automatic GitHub Integration (Recommended)
1. Push this repository to GitHub.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import this repository.
4. Click **Deploy**. Vercel will build and serve it on a global edge CDN automatically.

### Option 2: Terminal Deployment via Vercel CLI
```bash
# In the project directory:
npx vercel

# To deploy directly to production:
npx vercel --prod
```
